Wearable Scoliosis Detection System

IoT Embedded Hardware & Neural Angle Regression
95.4% Angle Accuracy <15ms Latency

An end-to-end wearable health sensor system for posture monitoring and non-invasive spinal Cobb angle detection. Uses an ESP32 microcontroller with an array of ADXL345 3-axis accelerometers to collect real-time spatial orientation data fed into a custom neural regression model.

System Architecture Flowchart: 
graph LR
    A[ESP32 Accelerometer Array] -->|I2C Data Stream| B[Feature Normalization]
    B -->|Normalized Tri-Axial Pitch/Roll| C[Neural Network Regression]
    C -->|Cobb Angle Prediction| D[Real-Time 3D Spine Dashboard]

    style C fill:#FDFFF5,stroke:#000,color:#000
    style D fill:#FDFFF5,stroke:#000,color:#000

Technical Contributions & Proof:

  • Designed multi-node ADXL345 sensor placement topology along thoracic and lumbar spine segments.
  • Implemented sensor calibration algorithms for noise reduction and tilt vector extraction.
  • Trained compact neural regression models yielding 95.4% accuracy compared to clinical radiography ground truth.
  • Deployed WebSocket communication protocol streaming telemetry at 60 FPS under 15ms latency.
